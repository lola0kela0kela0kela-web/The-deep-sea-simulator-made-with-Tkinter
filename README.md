# The-deep-sea-simulator-made-with-Tkinter

> [!NOTE]
> Designed for scrolling on macbook, might not work on other devices.
> Được thiết kế cho việc lướt trên macbook, có thể không lướt được trên các thiết bị khác.

<img width="2846" height="1618" alt="image" src="https://github.com/user-attachments/assets/1200b160-cc23-450d-a704-282e5f82c4da" />

## 🌊 Features
- **Interactive Scrolling:** Seamlessly travel down to 1,000 meters deep.
- **Educational Snippets:** Quick, fun facts about each marine species.
- **Visual Assets:** Custom PNG illustrations enhanced with a watercolor filter.

## 🛠️ Requirements
- **Python:** 3.10 or higher (Developed on 3.14.0)
- **Tkinter:** Included in the standard Python library (no installation needed)

## 💻 Installation & Usage
1. **Clone or download** this repository.
2. Ensure you have all the required image assets inside an `image/` folder relative to the script.
3. Open your terminal or command prompt and run the application:

```bash
python deep_sea_simulator.py
python deep_sea_simulator.py
```
